# Thrilok Chaitanya — Portfolio

Personal portfolio built with Next.js, React, TypeScript, and Sass.

Live website: [thrilok-chaitanya-portfolio.vercel.app](https://thrilok-chaitanya-portfolio.vercel.app/)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Available commands

```bash
npm run build
npm run lint
```

The portfolio presents projects in network security monitoring, multimodal sentiment analysis, and PDF outline extraction. Some profile details are marked `NEED TO BE FILLED` where information has not been provided.
